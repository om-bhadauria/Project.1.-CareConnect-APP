# **App Name**: IndoreCare

## Core Features:

- Doctor List Display: Display a list of doctors in Indore with their specialization and contact details from a JSON file. Allow filtering by specialization.
- Appointment Booking Form: Allow users to select a doctor and an available time slot. Store appointment details in local storage.
- Schedule View: Allow users to view their booked appointments, retrieved from local storage.
- AI Tool for Suggesting Doctors: Use a generative AI tool to recommend doctors based on a brief description of the user's symptoms.
- Video Summaries for Doctors: If the contact details of a given doctor include a link to a video, show an AI-generated summary of the video.
- Confirmation Messaging: Show a confirmation message upon successful booking.

## Style Guidelines:

- Primary color: Soft blue (#79A3B1) to evoke trust and serenity, referencing a medical context without being overly clinical.
- Background color: Light grey (#F0F4F5), nearly the same hue as the primary color, for a clean and calm backdrop.
- Accent color: Muted teal (#458A8A), analogous to the primary but darker, to draw attention to key interactive elements.
- Body and headline font: 'PT Sans', a humanist sans-serif combining modernity and warmth suitable for both.
- Use flat, simple icons in the primary color to represent different specializations and appointment functions.
- Maintain a clean and organized layout with clear separation of sections for doctor listings, booking forms, and schedule views.
- Use subtle transitions and animations for loading and form submission to enhance user experience.
